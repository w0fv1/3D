我的 3D 打印模型适配与个人改进记录。模型文件统一放在 Releases；仓库源码不含任何模型文件。

默认采用单色 PETG，颜色按用途选择：

- 普通工具、收纳用品：黑色。
- 玩具、摆件：白色。
- 调色板：固定白色，便于观察和判断颜色。
- 有特别要求时，以具体模型说明为准。

此约定用于后续新增和更新的模型；历史版本的实际材料与参数以对应 Release 和 3MF 为准。

## 目录约定

- 仓库只跟踪 `README.md` 与 `.gitignore`，其余内容一律忽略。
- 每个模型的 3MF 工程、SHA256 校验和与说明都在对应 Release 中。
- 源网格、脚本、切片、试摆等中间文件不入库。
